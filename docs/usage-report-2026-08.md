## 九、其他观察与建议

1. **单一模型依赖**：`flash-20260731` 占 Token 81%、成本 51%，建议关注其上游价格/可用性变化，必要时引导分流至新上线的 `flash-vision-exp`、`GLM-5.3-Flash` 等。
2. **头部用户集中**：3 个用户占 87.6% 消耗，建议评估其计费组/配额策略与风控。
3. **8 月新模型已上线但暂无消耗**：6 个「上新」模型（Qwen3.8 Flash、Hy4 Preview、DeepSeek-V4-Pro-0813、GLM-5.3、DeepSeek-V4-Flash-Vision-Exp、GLM-5.3-Flash）均已在渠道与计费中配置，等待实际调用；上线后成本会上升，需留意资源包/余额。
4. **上游折扣**：当前上游实际应付仅为刊例的 76.4%（469.58/614.84），存在约 24% 折扣；后续上游调价会直接影响毛利，建议定期核对账单。
5. **成功率 99.18%**：99 条失败多为瞬时错误，可考虑开启失败重试/降级到备用渠道进一步提升可用性。
